# Файл с ключевыми фразами для отслеживания
# По одной фразе на строку
# Строки, начинающиеся с #, игнорируются (комментарии)
# Пустые строки также игнорируются

# Примеры ключевых фраз:
Внимание всем! Воздушная тревога!
ВНИМАНИЕ ВСЕМ! Воздушная тревога!

# Формулировка с картинки-плашки (там нет слова «всем»).
# Тем же файлом проверяется и текст, распознанный с картинки, поэтому
# фраза обязана совпадать с надписью на плашке.
Внимание! Воздушная тревога!
